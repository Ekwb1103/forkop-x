# Переименование Rust X в Xrust

Репозиторий: https://github.com/Screamshow/xrust. Переименован существующий
репозиторий; история, теги и прежние релизы сохранены. Старый GitHub API
адрес Screamshow/rust-x проверен после переименования: он перенаправляет
на новый репозиторий, latest остаётся rust-x-v0.0.22.

В Forkop изменены отображаемые названия компонента, диагностики, уведомлений
и подсказок Tailscale. Обновлены README и действующие инструкции ядра,
описания пакетов, название будущих GitHub-релизов и ссылки release-инструментов.
Локальный origin ядра указывает на новый адрес; upstream оставлен прежним.

Для старых установок сохранены:

- пакет rust-x, component rust_x и UCI variant rust-x;
- /usr/lib/rust-x, wrapper sing-box и формат версии executable;
- Cargo feature rust-x, существующие source/crate names и лицензия GPL-3.0-only;
- rust-x-v* теги и прежние имена файлов релизов;
- https://mirror.51343.ru/forkop/rust-x/latest.json и архивы зеркала;
- scripts/release.py --rust и локальный checkout artifacts/tachyon-core.

Миграция конфигурации или переустановка ядра не нужна. Старый Forkop продолжит
показывать Rust X; новое отображение появится после установки обновлённого
Forkop. Старые release notes и исторические отчёты не переписывались.

Проверены 14 адресных frontend-тестов, TypeScript, сборка LuCI и 15 тестов
подписанного release workflow. Новые релизы, теги и пакеты не публиковались;
установленные роутеры и зеркало не изменялись.
