# Bytecode: фактическое место на ВМ — 8 октября 2026

Быстрая проверка по запросу пользователя. Роутер 192.168.90.1 не изменялся. На двух существующих ВМ текущий bytecode-кандидат уже завершил install/restart/migration, отказ несовместимого lifecycle, восстановление DNS, точный текстовый пакетный откат и переустановку. Reboot этого кандидата ещё не выполнялся.

## Кандидат и метод

Компилятор закреплён на upstream ucode commit `3f64c8089bf3ea4847c96b91df09fbfcaec19e1d` (версия ВМ24). Формат bytecode 0x01. Компилируются 64 из 68 модулей; core/common.uc, core/uci.uc, dns/apply.uc и dns/reload.uc остаются текстовыми для DNS recovery. Entrypoint и package hooks остаются текстовыми. FORKOP_BYTECODE по умолчанию 0: обычная сборка не изменена.

До изменения ВМ сохранены package/service state, UCI и hash core. Forkop остановлен один раз, чтобы исключить запись worker в ходе замера. Один и тот же /usr/lib/forkop последовательно переключён bytecode → текст → bytecode → текст из точных сохранённых payload. После каждого переключения выполнен sync и измерены du -sk, df -k / и сумма wc -c всех .uc. Пакеты и резервные копии вне измеряемого каталога не удалялись. Эти пары измеряют замену library payload; не включают эффект скачивания архивов или изменения package DB.

## Результат

Обе ВМ используют ext4 без сжатия файлов.

Текстовые .uc: 1877824 байта; bytecode-кандидат с четырьмя recovery sources: 1352359 байт. Разница **525465 байт / 513,15 КиБ логического размера**. 24 байта отличия от прежнего source inventory объясняются заменой version placeholder на 2.0.0.

## Восстановление и границы

Обе ВМ возвращены на текстовый backend через точный rollback пакет. Проверены рабочий runtime с 8 секундами стабильности, DNS, исходная UCI и неизменный executable core; runner завершился `TEXT_BACKEND_RESTORED rc=0`. Временные production-подмены удалены восстановлением библиотеки; test backups/logs остаются отдельно. Ядро X не менялось.

На пользовательском роутере только read-only проверен mount: overlay upper находится на f2fs без объявленного compression option. Этот факт не заменяет df/du замер после установки; на нём экономия 528 КиБ не доказана. Другие squashfs/JFFS2/UBIFS/compressed storage требуют отдельного измерения.

Bytecode остаётся экспериментом: полный reboot, clean install, широкая migration matrix и проверка независимого пакетного recovery ещё впереди. Не включать его в описание уже принятого релиза. Подготовленные scripts/compile-backend-bytecode.py в каталоге forkop и scripts/build-bytecode-compiler.sh обслуживают opt-in сборку, не включают её по умолчанию.
