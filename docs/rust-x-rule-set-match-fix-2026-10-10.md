# Rust X: rule-set match, проверка без релиза

Дата: 2026-10-10. Версия workspace оставлена 0.0.4.

Установленный Rust X на 192.168.90.1 воспроизводит ошибку на точной
команде Forkop: `sing-box rule-set match --format binary <path> forkop-validation.invalid`.
Значение `binary` принимается за путь; после устранения этого препятствия
старый CLI также не принимал позиционный запрос, требуя --domain/--ip.

Исправление в crates/core-cli/src/rule_set.rs добавляет отдельный разбор
аргументов match: --format/-f, inline-формы, позиционный домен/IPv4/IPv6,
проверку числа аргументов и неизвестных флагов. Явный формат binary/source
определяет парсер; существующие --domain/--ip и автоматическое определение
формата при отсутствии флага сохранены. Отсутствие совпадения даёт успех,
повреждённый SRS — ошибку. Сверен интерфейс эталонного sing-box:
https://github.com/SagerNet/sing-box/blob/v1.12.0/cmd/sing-box/cmd_rule_set_match.go.

Четыре focused CLI tests прошли, включая реальные compile/read SRS,
отсутствие совпадения, IP/domain-запросы, неверные аргументы и повреждённый
бинарный файл. Лог: tmp/rust-x-tools/rule-match-tests.log.

ARM64-кандидат проверен на физическом GL-MT6000:
- реальный twitch.srs: установленный CLI exit 1, кандидат exit 0;
- domain/IPv4/IPv6, source/binary, флаги до/после пути и inline-форма прошли;
- повреждённый SRS отклонён;
- полный forkop manual_restart завершился успешно за 25.67 секунды.

В полном перезапуске временная PATH-обёртка направляла только rule-set match
на кандидат; все остальные команды и запущенный runtime использовали
установленный 0.0.4. Подтверждён один вызов обёртки. UCI и установленный
бинарный файл совпадают с исходными SHA-256; DNS и статус Forkop проверены.
Кандидат и скрипт запуска удалены из /tmp роутера. Резервные состояния и
логи оставлены в /tmp/rust-x-match-probe.PilFjO.

Этот замер полного пути находится в прежнем диапазоне 25–30 секунд;
заметное ускорение полного ручного перезапуска не подтверждено. Ранее
обычный forkop restart без принудительного обновления источников занял
20.42 секунды, с наблюдаемой готовностью сервиса/DNS через 14.42 секунды.

На существующей OpenWrt 25 x86_64 ВМ 192.168.1.1 те же CLI-проверки
прошли: исходный CLI exit 1, кандидат exit 0, положительные/отрицательные
сценарии успешны. UCI и установленный бинарный файл сохранены по SHA-256.
Доказательства: /tmp/rust-x-match-probe.eHDOIf. Временный кандидат удалён.

Релиз, тег и публичные пакеты в этом шаге не создавались.
