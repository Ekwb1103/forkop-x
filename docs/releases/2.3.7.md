## Подписки

- Обновление подписок на Xrust применяется без перезапуска ядра и разрыва установленных соединений. Добавленные серверы появляются в выборе, текущий выбор сохраняется, если сервер остался в группе.
- Если конфигурация не изменилась, обновление не затрагивает работающие соединения.
- Для sing-box без поддержки hotreload применения сохранён обычный перезапуск.
- При ошибке hotreload восстанавливаются предыдущая конфигурация, выбранные серверы и данные дашборда.

## Выбор серверов

- Исправлен сброс ручного выбора на первый сервер после обновления подписки.
- Выбранные селекторы вручную сохраняются при перезапуске Forkop X.

## Уведомления

- Добавлен явный алерт при ошибке применения подписки и результата восстановления.
- После успешного применения он снимается.

## Совместимость

- Для полного набора исправлений необходимо обновить Forkop X и Xrust.
- Сохранение выбора между запусками ядра использует RAM-кеш. После полной перезагрузки роутера выбор сбрасывается.
