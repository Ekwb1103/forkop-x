## Маршрутизация и DNS

- При перезапуске Forkop X сохраняется локальная настройка DNS. Убрано временное переключение на внешние DNS-серверы, из-за которого клиенты могли кешировать реальные адреса вместо FakeIP.
- При явной остановке Forkop X или неудачном перезапуске восстанавливаются прежние настройки DNS.

## Дашборд и мониторинг

- Для правил, направляющих весь трафик устройства в выбранную секцию, теперь отображается пояснение «Весь трафик устройства» с IP-адресом или подсетью.

## Применение настроек

- Убрано фиксированное ожидание LuCI перед подтверждением изменений, если меняются только настройки Forkop. Для смешанных изменений и при ошибке проверки сохранена штатная задержка. Подтверждение и защитный откат LuCI сохранены.
