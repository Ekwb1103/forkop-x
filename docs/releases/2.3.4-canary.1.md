Forkop 2.3.4 canary 1

- Добавлена вкладка Tailscale: подключение роутера по ключу, доступ к LuCI и дополнительное разрешение доступа к локальной сети. Отдельный пакет Tailscale не требуется.
- Нужен Rust X 0.0.16 с поддержкой нативного Tailscale. С sing-box и несовместимым Rust X функция недоступна.
- Добавлены статус подключения и раскрываемые логи соединения. Ключ не сохраняется в конфигурации.
- Подключение сохраняет идентификатор при перезапуске; при откате Forkop ниже 2.3.4 удаляются сетевые правила и прекращается нативный удалённый доступ.
- Пользовательский Tailscale работает отдельно от временной Lite-поддержки.

Для доступа к LAN требуется одобрение маршрута в панели Tailscale. Функция экспериментальная; canary предназначен для тестирования.
