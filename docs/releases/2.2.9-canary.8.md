Forkop X 2.2.9-canary.8

- Download and validate newly declared remote rule sets before applying live configuration. Reject unavailable or invalid lists instead of silently installing an empty placeholder, preserving the previous working policy.
- Show a translated yellow LuCI warning when required lists cannot be prepared, explaining that changes were not applied and the previous configuration remains active.
- Clean unused managed rule-set files and validation markers from flash and RAM only after successful application, preserving rollback files while a candidate is being prepared.
- Recover automatically when a failed list edit is cancelled or replaced: validate the pending generation against current settings and prepare current sources before retrying its runtime apply.
- With Rust X 0.0.11, close affected TCP/UDP sessions after routing changes, including individual domains/IP-CIDRs, entries inside lists and transfers between connection sections. Preserve independent sessions and retain compatibility with older cores and the Sing-Box X restart path.

This supersedes the withdrawn 2.2.9-canary.1/Rust X 0.0.10 mirror combination. Direct kernel-forwarded connections remain untouched. Separate subscription updates, DNS failover and immutable listener changes retain their existing restart policy.
