## Tailscale

- Добавлена вкладка Tailscale для удалённого доступа к роутеру. Подключение работает через Rust X без установки отдельного пакета Tailscale.
- Доступ к LuCI, SSH и локальной сети настраивается отдельно. Для доступа к локальной сети требуется одобрить маршрут в панели Tailscale.
- Добавлены статус подключения и журнал событий. Идентификатор подключения сохраняется при перезапуске.
- Нативный Tailscale работает отдельно от временной Lite-поддержки. Функция экспериментальная, для всех возможностей нужен Rust X 0.0.17 или новее.

## Интерфейс и дашборд

- Устранено зависание открытия LuCI при ожидании информации о возможностях ядра.
- Исправлена мобильная вёрстка: названия секций больше не сжимаются в столбик, кнопки и информация о подписке корректно переносятся на узких экранах, обновлена вкладка диагностики.
- Исправлена проверка задержки в группах Priority.
- Добавлены подсказки элементов управления на вкладке компонентов при наведении.

## Работа ядра

- Исправлено применение повышенного лимита файловых дескрипторов к пакетной службе ядра, чтобы избежать отказов при большом количестве соединений.
