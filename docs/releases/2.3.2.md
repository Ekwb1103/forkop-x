## Rust X

- Добавлено экспериментальное ядро Rust X. Установка и обновление доступны в разделе «Компоненты».
- При обновлении Forkop X сохраняется выбранное ядро. Новые установки по-прежнему используют Sing-Box X.
- На Rust X изменения списков и правил применяются без перезапуска ядра. При ошибке восстанавливается прежняя конфигурация.

## Секции и списки

- Добавление, удаление и перенос списков между секциями применяются за один reload. Уже загруженные исправные источники используются из кеша, скачиваются только недостающие или повреждённые.
- Новые списки загружаются и проверяются до применения настроек. Если список недоступен или повреждён, сохраняется прежняя рабочая конфигурация, а LuCI показывает предупреждение.
- Исправлено восстановление после неудачного изменения списков. После отмены или исправления настроек изменения можно применить повторно.
- Исправлен откат при удалении списков. Прежние файлы сохраняются до успешного применения, затем неиспользуемые данные очищаются с флеш и из RAM.
- Исправлен учёт TCP/UDP и ограничений портов секции при применении списков через nftables.

## Подписки

- Убраны лишние перезапуски ядра при обновлении подписок: если итоговая конфигурация не изменилась, активные соединения сохраняются.
- Кеш подписок и метаданные сохраняются при перестановке источников и переносе между секциями.
- Исправлено использование сохранённых подписок после обновления или смены ядра, в том числе при запуске без доступа к источнику подписки.

## Маршрутизация и DNS

- Настройка «Отключить QUIC» теперь блокирует также прямой UDP/443 клиентов для IPv4 и IPv6.
- Исправлена совместимость обхода собственного трафика Forkop с mwan3. Исходящий UDP ядра больше не захватывается повторно правилами FakeIP.
- Сокращены лишние проверки nftables для прямого трафика и трафика с уже назначенной маркировкой.
- Исправлена обработка запросов на отдельных DNS-входах: они направляются в DNS до определения протокола.
- После запуска и обновления подписок проверяется готовность сетевых входов ядра. При неудачном обновлении восстанавливается прежняя конфигурация.
- Убраны преждевременные переключения DNS во время запуска ядра.

## Обновление и смена ядра

- Исправлена ошибка загрузки пакетов для отката из репозитория, из-за которой обновление Forkop или смена ядра могли прерываться.
- Исправлен автоматический запуск после смены ядра, когда его API временно недоступен.
- Кеш FakeIP разделён между семействами ядер. При обновлении внутри одного семейства кеш сохраняется.
- Добавлена очистка оставшихся временных каталогов обновления и незавершённых загрузок.
- Зависшие загрузки компонентов и списков прерываются. Медленные загрузки продолжаются, пока поступают данные.
- Исправлена доступность кнопки «Перезапустить Forkop X» при сбое работающего сервиса.

## Дашборд и мониторинг

- Добавлено отображение памяти процессов Forkop X и выбранного ядра. Виджет ядра показывает фактическую резидентную память процесса (RSS).
- Задержки серверов обновляются без полной перерисовки карточек. Убраны лишние обновления неизменившихся элементов интерфейса.
- Убрано нежелательное автозаполнение поля одноразового ключа Tailscale менеджерами паролей.

Rust X остаётся экспериментальным. Hot Reload требует поддерживаемой версии Rust X, для Sing-Box X сохраняется применение с перезапуском ядра.
