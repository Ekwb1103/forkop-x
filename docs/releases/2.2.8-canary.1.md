Forkop X 2.2.8-canary.1

- Match the own-traffic bypass bit using a mask instead of requiring an exact packet mark.
- Preserve bypass when mwan3 adds its WAN policy bits, preventing Forkop's outgoing UDP traffic from being captured again by the FakeIP TPROXY rules.
- Add a regression check for generated nftables rules with combined outbound marks.

Verified with nftables generation and atomic-apply tests and real marked UDP packets on the OpenWrt 25.12.5 VMware VM. The old rule bypassed only the plain Forkop mark; the fixed rule also bypasses marks carrying either WAN policy bit while leaving traffic without the Forkop bypass bit eligible for interception. Rust X FakeIP cache and missing-record fixes are released separately in Rust X 0.0.9; this release does not automatically switch or upgrade the installed core.
