## Маршрутизация и DNS

- Добавлена настройка «Использовать реальные IP-адреса для WhatsApp». При её включении домены WhatsApp исключаются из выдачи FakeIP. Для работы нужны загруженные списки подсетей Meta в активной секции маршрутизации без фильтров устройств и портов. Устройства должны использовать DNS роутера.
- Добавлена проверка настроек WhatsApp при сохранении. Если включена выдача реальных IP-адресов, LuCI предупреждает при удалении или изменении последней подходящей секции Meta.

## Блокировка QUIC

- Добавлена отдельная настройка блокировки QUIC только для трафика, направляемого через секцию connection.
- Глобальная блокировка QUIC имеет более высокий приоритет.

## Смена ядра

- Кеши FakeIP разных семейств ядер сохраняются после переключения. При возврате к прежнему ядру или откате его кеш остаётся доступен.

## Tailscale

- Добавлен цветной индикатор состояния подключения.
