# Forkop X 2.0.0-canary.2

- Исправлено отображение причины маршрутизации в мониторинге: точное совпадение из Clash API теперь показывается отдельно, без длинного сокращённого правила. Например, `domain_suffix=chatgpt.com` или `domain_suffix=oaistatic.com`.
- Добавлена поддержка данных совпадения из Sing-Box X 1.0.1 для доменов, суффиксов, keyword, RE2-регулярок и CIDR. Для ядер без этих данных сохранено прежнее поведение; маршрут по умолчанию не наследует чужое совпадение.

Если после обновления браузер показывает старое длинное правило, обновите страницу через Ctrl+F5. Для точного совпадения нужен Sing-Box X 1.0.1; версия установленного ядра сохраняется при обновлении Forkop, его обновление выполняется отдельно через компоненты.
