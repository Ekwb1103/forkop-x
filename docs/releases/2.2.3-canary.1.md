# Forkop X 2.2.3-canary.1

- Исправлено сохранение состояния активного Forkop при смене ядра: временная неготовность API больше не приводит к пропуску автоматического запуска. Явно остановленный сервис не запускается.
- Настройка «Отключить QUIC» теперь блокирует также прямой UDP/443 клиентов через nftables с явным ICMP-отказом для IPv4/IPv6. Сохранены локальные назначения, DNAT и прокси-марка; посторонние марки mwan3 не обходят блокировку.
- Изменение настройки QUIC пересобирает сетевые правила при Reload.

Проверено: полный переход Extended → Rust X на OpenWrt 25; пакетные проверки IPv4/IPv6, исключений и Reload на OpenWrt 24. Обе ВМ восстановлены. Проверки не гарантируют одинаковое время переключения на TCP во всех приложениях. Блокировка UDP/443 затрагивает и другие протоколы на этом порту; существующие offloaded-соединения могут потребовать переподключения.
