## Установка и обновление

- На новых установках ядром по умолчанию становится Xrust. Обновление существующей установки сохраняет выбранное ядро.
- На вкладке обновлений добавлен выбор версии Xrust из каталога зеркала, включая установку предыдущих версий.
- Установщик устанавливает необходимые зависимости до остановки Forkop. Убрана отдельная зависимость от пакета `flock`.
- Исправлено переключение репозиториев OpenWrt на зеркало: поддерживаются разные пути исходных зеркал, а при невозможности замены сохраняются штатные репозитории.

## Подписки и совместимость

- Разрешены любые подписки
- Узлы с протоколами, отсутствующими в Xrust, исключаются при формировании конфигурации.
- Неподдерживаемые VLESS Encryption и REALITY `pqv` больше не отбрасываются молча: несовместимые узлы пропускаются либо отклоняются с ошибкой.
- Сохранена передача отпечатка сертификата Hysteria2 `pinSHA256` в конфигурацию ядра.
- Для профилей uTLS `android` и `360` при работе с Xrust используется `chrome`.

## Компоненты

- Удалена поддержка ByeDPI. При обновлении очищаются связанные с ним правила и настройки.
- При установке Zapret-Manager включается его веб-интерфейс.
- Исправлена обработка FakeIP-соединений TorrServer с режимом Direct.
- Исправлено включение init-скрипта TorrServer Direct в пакеты, собираемые через OpenWrt SDK/buildroot.
- При полном удалении очищается кэш наборов правил Xrust, включая прежний путь кэша.

## Интерфейс и внутренняя оптимизация

- В выборе языка Forkop X вариант «Как в LuCI» удалён.
- Уменьшен размер JavaScript интерфейса за счёт сохранения кириллицы в UTF-8.
- Удалены неиспользуемые внутренние обработчики и вспомогательные функции backend.
- Исправлена передача токена Clash API, когда в конфигурации задан секрет.
