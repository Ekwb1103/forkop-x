Forkop X 2.2.7-canary.1

- Show Forkop X in Services info while preserving process RSS and active core identification.
- Isolate FakeIP cache databases between core families, retaining the current cache during same-family updates and Extended/compressed transitions.
- Remove the previous cache after a verified successful core switch, and remove a failed candidate's cache only after verified runtime rollback.
- Clean abandoned updater directories and partial core downloads while preserving live operations and recovery packages, including interrupted core replacements.
- Abort stalled component and rule-set downloads without rejecting slow but progressing connections or shortening existing package download timeouts.

Verified on the OpenWrt 25.12.5 VMware VM with real core switches, startup failure and rollback, and SIGKILL before package replacement. Core packages are released separately; this release does not automatically switch or upgrade the installed core.
