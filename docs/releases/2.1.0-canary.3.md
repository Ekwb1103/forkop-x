## Временная поддержка

- Исправлено обновление старых конфигураций: адрес оператора теперь добавляется автоматически, если параметр отсутствует. Это включает автоматические проверки связи, добавленные в canary.2.
- Существующий адрес оператора сохраняется. Для явного отключения проверок можно задать `support_operator_ip='disabled'`.
