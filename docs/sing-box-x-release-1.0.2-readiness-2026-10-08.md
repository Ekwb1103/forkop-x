# Готовность следующего Sing-Box X 1.0.2 — 2026-10-08

Объединён hardening/uTLS из чата «Проверить совместимость Forkop X», XHTTP из
«Добавить XHTTP в sing-box X» и новые TLS/REALITY fingerprints из последнего
podkop-engine v1.14.2-r12. Итоговая версия артефактов теперь 1.0.2, не 1.0.3.

Проверены unit/race, ARM64/x86_64, OpenWrt VM, физический GL-MT6000,
JSON/SRS, DNS, Clash API и запуск/перезапуск. После нового переноса Firefox 148
текущая подписка прошла 61/61 на VM и 61/61 на роутере. Старые расширенные
матрицы выполнены до обновления fingerprints; новая полная Xray 26.9.x
матрица по просьбе пользователя не запускалась.

По новой инструкции пользователя не создавались дополнительные бэкапы и не
выполнялся пакетный откат. Проверенный локальный кандидат APK 1.0.2-r1 оставлен
на роутере вместо 1.0.1-r1; offline обновление и последующий запуск прошли.
DNS, Clash API и HTTPS 204 подтверждены. Также оставлена backend адаптация
capability XHTTP; frontend bundle не менялся. Установка кандидата на собственный
роутер — узкое исключение по новой просьбе пользователя, не публичный mirror путь.

с пустым описанием: https://github.com/Screamshow/sing-box-x/releases/tag/1.0.2.

Скачаны и проверены все семь публичных артефактов, включая размеры и SHA-256.
Публичный APK индекс для ARM64/x86_64 возвращает 1.0.2-r1; fetch, SHA-256
и проверка подписи прошли. Запущен forkop-canary-mirror.service; canary.json,
releases.json и шесть пакетов текущего canary 2.1.0-canary.2 проверены.

локальные артефакты. Установка подписанного пакета на роутер в этом шаге
не выполнялась; оставлено ранее проверенное ядро с тем же бинарником.
