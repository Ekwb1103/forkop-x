# XHTTP кандидат: ARM64 GL-MT6000, 2026-10-08

По разрешению владельца проверен роутер 192.168.90.1: GL.iNet GL-MT6000,
OpenWrt 25.12.5, mediatek/filogic, aarch64_cortex-a53. Исходное ядро X 1.0.1
(`1.14.2-x-1.0.1`), Forkop работал и был включён.

## Метод и сохранность

До изменения сохранены список пакетов APK, состояние/включение сервисов,
Forkop/sing-box/DHCP UCI, generated config, backend runtime/UI/generator,
init script и SHA-256 этих файлов. Приватные данные оставались в root-only
временном каталоге роутера; в локальном отчёте и evidence нет подписки, HWID,
серверных адресов, UUID или ключей.

Пакеты не устанавливались и не обновлялись. Бинарник кандидата из /tmp
временно bind-mounted поверх /usr/bin/sing-box вместе с тремя изменёнными
backend файлами. До отдельного процесса sing-box Forkop останавливался,
чтобы watchdog не вмешивался. Тест выполнялся отсоединённым процессом с guard
на 15 минут и EXIT/TERM восстановлением, поэтому прерывание чата его не отменяло.

Проверена длина 8 599 568 байт и SHA-256 переданного ARM64 бинарника:
`1fdad9b2a3b54680e33fee94d5e33542535b5527497b5aeed8701b0de7c8f772`.
Он сообщает `1.14.2-x-1.0.3`, Go 1.26.8 linux/arm64, CGO disabled и Features
transport.xhttp / transport.xhttp.http1 / transport.xhttp.http2, без with_quic.

## Результаты

- Candidate check текущей конфигурации и изолированной подписки прошёл.
- Forkop start и restart с кандидатом прошли: DNS 127.0.0.42, Clash API,
  реальный HTTPS через штатный mixed/SOCKS inbound 192.168.90.1:2080.
- Текущая пользовательская конфигурация: 61 VLESS outbound, 9 ruleset.
  UI правильно сообщает XHTTP=1, Extended=0. Настройки пользователя не менялись.
- Подписка загружена штатным механизмом INCY/HWID и нормализована штатным parser:
  62 записи outbound, из которых одна URLTest группа; 61 сервер: 58 TCP REALITY,
  один gRPC REALITY, два XHTTP TLS.
- Массовый пинг через Clash API /delay, тот же механизм дашборда, на отдельном
  ARM64 процессе кандидата: три прохода 61/61, 61/61, 61/61 — 183/183 без ошибок.
  В каждом прошли все 58 TCP REALITY, gRPC и два XHTTP (Обход LTE v1/v2.1).
  URLTest делает HTTPS HEAD через каждый outbound; это функциональная проверка,
  не измерение throughput и не гарантия обхода блокировок конкретной LTE сети.
- Синтетический список 10 003 доменов, JSON и скомпилированный SRS:
  large/nested/malformed/truncated/unsupported/changed проверки прошли.
  Cache publication, unchanged refresh, last-known-good, RAM-only cache и
  последующая promotion прошли.
- Для обоих форматов списков реальный HTTPS через XHTTP работает; Clash API
  подтвердил rule_set=list-route-source / list-route-binary и проверяемый host.
- RAM-замеры кандидата 1.0.2 не повторялись. QUIC и HTTP/3 не добавлялись.

Первые тестовые попытки не засчитаны: фиксированная пауза 12 секунд проверяла
Forkop раньше завершения запуска на этом роутере; заменена ожиданием статуса.
Минимальный изолированный config не имел массивов route.rules/rule_set;
helper теперь создаёт их, чтобы тест действительно добавлял правило списка.
При загрузке большого списка проверка через секунду была раньше готовности
inbound; добавлено ожидание Clash API и ограниченный retry соединения.
После исправления fixture все перечисленные проверки прошли.

## Восстановление и ограничения

Сняты bind mounts, завершены тестовые процессы, восстановлены исходные файлы
и X 1.0.1. Проверены SHA-256 бинарника, UCI, generated config, backend и init
script; список пакетов совпал с исходным. Forkop работает и включён; DNS и
Clash API доступны, HTTPS через штатный SOCKS вернул 204. Временные подписки,
конфигурации и файлы теста удалены после сохранения обезличенных результатов.

Evidence: `artifacts/sing-box-x/work/xhttp-evidence/router90/`:
`runtime-and-subscription.log`, `subscription-latency-3rounds.json`,
`list-validation.log`, `list-routing.log`, `list-routing-and-restoration.log`,
`final-restoration.log`.

Проверка ARM64 runtime закрыта. Пакетная установка/обновление/откат кандидата
ещё не проверены: локальные пакеты намеренно не устанавливались в обход зеркала.
Нет длительного нагрузочного теста. Совместимость контролируемого REALITY
стенда Xray 26.9.x ограничена, но все REALITY серверы текущей подписки прошли.
Релиз и зеркало не обновлялись; артефакты остаются локальным кандидатом.

Нумерация: GitHub API на момент проверки показывает публичные 1.0.0/1.0.1.
1.0.2 был локальным baseline с hardening/uTLS, 1.0.3 — локальный кандидат с
добавленным XHTTP. Номер следующего публичного релиза можно выбрать отдельно;
новые APK/IPK не должны заменять опубликованную ревизию с другим содержимым.
