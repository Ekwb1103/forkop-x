# Rust X 0.0.4: публикация и проверки

Дата: 2026-10-10. Коммит релиза:
`ba1c6379c17f65acaf5e870e49333249d2c75aac`.

Опубликован https://github.com/Screamshow/rust-x/releases/tag/rust-x-v0.0.4.
Release workflow 38048266799 завершился успешно. Описания 0.0.3 и 0.0.4
оформлены по образцу ранних релизов: список изменений и благодарность
Dushnilin/tachyon-core.

Исправление 0.0.4 принимает одиночные IPv4/IPv6 в DNS source_ip_cidr и
ip_cidr как /32 и /128. Явные префиксы и некорректные адреса сохраняют
строгую проверку. Также в релиз вошло ограничение платформ OpenWrt ARM64
и x86_64. DNS unit tests: 53 passed.

Пакеты APK 0.0.4-r1 и IPK 0.0.4-1 для двух архитектур подписаны/проверены
штатным финализатором на существующем зеркале. Приватный ключ не копировался.
Однократный TLS-сбой загрузки в GitHub устранён повторной загрузкой;
перед публикацией проверены длины и SHA-256 всех GitHub assets.

Проверены идентичность пакетов, исходный коммит, static ELF, архитектуры,
лимит размера и хеши двоичных файлов. Размеры: x86_64 11031904 байт,
aarch64 8982616 байт.

Зеркало обновлено:
https://mirror.51343.ru/forkop/rust-x/latest.json.
Публичный latest совпадает с releases/0.0.4/manifest.json; все четыре
публичных пакета проверены по длине и SHA-256.

На существующей OpenWrt 25 VM 192.168.1.1 выполнено штатное обновление
0.0.3 → 0.0.4 действием компонента Forkop. Сохранены состояние пакетов и
сервисов; SHA-256 обоих UCI до/после совпадает. Проверены конфигурация,
работа Forkop, DNS, SIGHUP без смены PID, отображение Rust X 0.0.4 и статус
обновления latest. Доказательства на ВМ:
`/tmp/release004-update.iGFLIJ` и `/tmp/rust-x-release004-state`.

На установленном ядре ВМ прошли пять изолированных DNS-сценариев с
одиночными IP источника/ответа и HUP между сценариями. Результаты:
`tmp/release004-vm25-hostip-results.json`.
Локальные пакеты: `tmp/rust-x-release-0.0.4/packages`.

Физический роутер 192.168.90.1 в этом шаге не обновлялся; там остаётся
проверенный локальный hotfix 0.0.3-r2, доступно штатное обновление до 0.0.4.
