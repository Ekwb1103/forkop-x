# Rust X: одиночные IP в DNS-правилах, роутер 192.168.90.1

Дата: 2026-10-10. Устройство: GL-MT6000, OpenWrt 25.12.5,
aarch64_cortex-a53; Forkop X 2.2.0-canary.1.

## Причина и исправление

Rust X 0.0.3-r1 отвергал `source_ip_cidr: "192.168.90.239"` при
компиляции DNS-правил: `missing /prefix length`. Проверка конфигурации
при этом принимала одиночный адрес. Штатная установка откатывалась на
Sing-Box X.

В `crates/core-runtime/src/dns/rules.rs` одиночные IPv4/IPv6 в
`source_ip_cidr` и `ip_cidr` нормализуются в /32 и /128. Явные CIDR
проверяются прежним строгим парсером; проверка диапазонов FakeIP не менялась.
Коммит в main Rust X: `17d6865a21002bdc7495147afd69c7c4da9c5442`.

## Проверки и установка

- 53 DNS unit tests прошли, включая точное совпадение одиночных IPv4/IPv6,
  отказ для соседнего адреса и отклонение некорректных адресов/префиксов.
- Cross-build для aarch64-musl и x86_64-musl завершился успешно.
- На роутере отдельный экземпляр кандидата прошёл пять сценариев DNS:
  совпадение/несовпадение источника, IPv6-ответ, evaluate/match_response по
  одиночным IPv4 и IPv6; проверена перезагрузка конфигурации.
- Собраны подписанные APK 0.0.3-r2 и IPK 0.0.3-2. Перед установкой APK
  проверены архитектура, идентичность, длина, SHA-256 и доверенная подпись.
- На роутере установлен Rust X 0.0.3-r2. Проверены реальная конфигурация,
  работа Forkop, DNS, HTTPS через SOCKS5 и SIGHUP с сохранением PID.
  Оба исходных UCI-файла сохранены и подтверждены по SHA-256.

Две ранние попытки остановлены защитными проверками и автоматически
откачены: изменение UCI после пакетной операции и слишком ранняя проверка
готовности. Итоговая установка восстанавливает исходные UCI после пакетной
операции и ожидает готовности сервиса; завершилась успешно.

Приватные резервные копии конфигурации и точный пакет отката Sing-Box X
остались на роутере в `/root/forkop-rust-x-hotfix-20261010`.
Рабочие доказательства: `tmp/router90-hostip-results.json`,
`tmp/router90-hostip-install-output.log`,
`tmp/rust-x-tools/bare-ip-tests.log`.

Пакеты исправления находятся локально в
`tmp/rust-x-hostip-hotfix/packages`. Публичные release assets и каталог
зеркала Rust X 0.0.3-r1 этим исправлением не изменялись.
