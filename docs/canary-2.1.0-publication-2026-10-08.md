# Публикация Forkop X 2.1.0-canary.1 — 8 октября 2026

По явному запросу пользователя опубликован prerelease с дословным пользовательским описанием:
https://github.com/Screamshow/forkop/releases/tag/2.1.0-canary.1

Исходники зафиксированы на существующей main, commit/tag target 2fe5ada976fafaba55d9789b69d2bfb561297936. Тестовые каталоги, APK/IPK других этапов, bytecode и AGENTS.md в commit не включены. Существующие незакоммиченные изменения оптимизации сохранены в релизном commit; остальные локальные untracked материалы оставлены.

Опубликованы ровно шесть ранее проверенных пакетов из tmp/canary210-validation/packages. До публикации черновика проверены размеры, SHA-256 GitHub assets и точное описание. Проверены 94 payload-файла против исходников git; различия только CRLF/LF в прежних support/lite.json и operator.pub. Содержимое ключей не выводилось.

Сервис forkop-canary-mirror.service запущен на существующем зеркале, Result=success, ExecMainStatus=0. Публичные canary.json, releases.json и canary/releases/2.1.0-canary.1/release.json содержат новый canary и все шесть правильных SHA-256. Все шесть пакетов повторно скачаны через публичный HTTPS зеркала и совпали с проверенным комплектом по размеру/SHA-256. stable.json до/после совпал побайтно, stable остаётся 2.0.0. Sing-Box X не публиковался и не менялся.

Создание тега запустило автоматический Build packages workflow 37722861867. Отмена подтверждена: workflow completed/cancelled, Build и Create Release cancelled. Автоматическая сборка не перезаписала проверенные release assets. Финальные SHA-256 GitHub assets повторно сверены. Несекретные результаты проверки сохранены в tmp/canary210-publication.

В журнале регенератора каталога остались прежние предупреждения о несовпадении пакетов архивов 1.1.2/1.1.3/1.1.4/1.1.5/1.2.2. Они наблюдались и до публикации, относятся к старым исключённым архивам; текущий canary проходит проверку и включён в каталог из 82 версий.
